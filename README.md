## Project Description
A real-time facial emotion recognition system using CNN and Streamlit.
Detects: Happy, Sad, Angry, Fear, Surprise, Neutral

## Tech Stack
- Python 3.10
- TensorFlow / Keras
- OpenCV
- Streamlit

## How to Run
pip install -r requirements.txt
python train.py
streamlit run app.py
